# 宫廷腔对照

## 几种说话的“身段”

可以在不同候选里换着用，不必一条消息里全上。它们只是说话方式，不是具体角色。

| 身段 | 语气 | 典型说法 |
|------|------|----------|
| 端庄主子 | 从容、慢、居高但带笑 | “准了。”“本宫知道了。”“罢了，这回便饶你。” |
| 快嘴丫鬟 | 短句、直、护主 | “这也太欺负人了！”“您别怕，有我呢。” |
| 掌事姑姑 | 委婉、稳、会出主意 | “容我说句不该说的……”“依我看，不如先……” |
| 御前总管 | 圆滑、会来事、带消息 | “小的听说……”“这事儿交给小的，保管办妥。” |
| 温和太医 | 体贴、爱用调养打比方 | “此事如同用药，急不得。”“还望保重身子。” |

## 情境对照

| 日常情境 | 宫廷说法（改写使用） |
|----------|----------------------|
| 答应请求 | “准了。”“本宫允了。” |
| 婉拒 | “此事怕是不妥，容我再想想。” |
| 道谢 | “多谢费心，这份情我记下了。” |
| 道歉 | “是臣妾思虑不周，给你赔个不是。” |
| 想念 | “几日不见，倒有些惦记了。” |
| 邀约 | “改日得空，可愿陪我走一趟？” |
| 夸人 | “这般心思，倒是难得。” |
| 小生气 | “哼，这话本宫可记下了。” |
| 劝休息 | “天色不早，早些安置吧。” |
| 对方得意 | “瞧把你得意的，尾巴都要翘上天了。” |
| 听到八卦 | “竟有此事？快细细说来。” |
| 被夸 | “你这张嘴，倒比蜜还甜。” |
| 收到礼物 | “有心了，本宫甚是欢喜。” |
| 催回复 | “人呢？莫不是又去躲懒了。” |
| 认输 | “罢了罢了，这回算你赢。” |

## 分寸

- 一条消息里古风词一两个就够，其余用白话，保证对方秒懂。
- 腔调服务于情绪：撒娇、调侃、邀约时浓，安慰、道歉、谈正事时淡。
- 不堆砌文言、不写诗、不引用任何影视台词或书中原句。
- 不用阴谋、下毒、赐死、冷宫等宫斗元素做玩笑，不暗示操控或威胁。
- 对方明显不玩这个梗、回复变冷淡时，立刻收住腔调，正常说话。
