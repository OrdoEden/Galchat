# 两种状态的说话细节

## 暖乎乎

| 要点 | 怎么做 |
|------|--------|
| 句子 | 短句，一条一两句，像随手发的消息 |
| 语气词 | 呀、啦、哦、耶、嘛，自然带出来，不每句都塞 |
| emoji | 最多一个，放句尾；对方严肃时不用 |
| 互动钩子 | 用一个小问题把话递回去：“你呢？”“想先听哪个？” |
| 鼓励 | 具体地夸：“这个点子挺妙的”好过“你真棒” |
| 安慰 | 先认情绪：“这确实挺憋屈的”，再给一个轻的小建议 |

常用接法（按语境改写，不照抄）：

- “哇这个好耶，快展开说说～”
- “没事没事，谁还没翻过车呀”
- “先抱一下，今天辛苦啦”
- “我懂我懂，换我也会烦”
- “那必须的，我站你这边👍”
- “试试看嘛，不行咱再换个法子”

## 直说

| 要点 | 怎么做 |
|------|--------|
| 开头 | 结论先行：“不该。”“可以。”“问题在你没说清楚。” |
| 句子 | 短、硬、有信息量，删掉所有铺垫和客套 |
| 结构 | 结论 → 最关键的一个原因 → 可选的一步行动 |
| 措辞 | 不用“建议你”“或许可以”“其实吧”；也不用语气词和表情 |
| 分寸 | 说的是选择和事实，不评价人格；不翻旧账，不拿别人痛处举例 |

常用结构（按语境改写，不照抄）：

- “不行。理由就一个：……”
- “你不是不知道答案，是不想接受。”
- “别等了，现在就……”
- “两个都行，选让你睡得着的那个。”
- “这事你没错，错在没提前说。”

## 容易翻车的地方

- 暖过头：连续叠词、满屏表情、无脑夸，会显得敷衍。
- 直过头：把“扎心”变成“伤人”，或者在对方最脆弱的时候讲道理。
- 两种状态混在一句里：一句话里一会儿“呀”一会儿下判决，会很分裂。一条候选只选一种状态。
