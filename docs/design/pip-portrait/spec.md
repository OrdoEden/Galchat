# 竖屏 PiP 设计 spec

## 是什么
Galchat 在录屏识别聊天时，用系统画中画小窗实时显示：对方此刻情绪、好感度分数与变化、一句行动建议。
竖屏预设内容尺寸 90 × 220 pt（9 : 22），由 Visyn 离屏光栅化成视频帧交给系统 PiP。

## 观看条件（决定一切）
- 真机上竖屏小窗宽约 95–100 pt，内容基本 1 : 1 显示 → 10cm 手机距离下看一块 90pt 宽的区域。
- 系统 PiP 窗口圆角约 10 pt，会裁掉四角 → 四角 10pt 内不放任何东西。
- 用户一边聊天一边瞟一眼：阅读时间 < 1 秒。优先级：分数/变化 > 情绪 > 建议 > 名字 > 状态。
- 正文不低于 9.5pt，关键信息 ≥ 12pt。

## 必含元素
- 「Galchat」字样（OCR 遮挡锚点，需清晰可读，与「好感度」字高相近）
- 「好感度」字样（OCR 锚点，水平中心在「Galchat」左边缘右侧）
- 头像（首字粉色渐变 或 识别到的立绘）、对方名字（可能很长：「录屏与画中画」「Alexandra Wang」）
- 心跳 GIF（heartbeat / heartflutter / heartbreak，96px 像素风爱心）
- 分数 0–100 或「—」、变化 ±n
- 情绪（≤5 字：轻松/平和、不满/试探、愤怒/冲突、高度紧张、等待分析、判断失败），按语气着色
- 建议（以「 · 」分隔的 1–3 段短语；或一句「打开聊天，等待分析」）
- 状态（Jev 分析中 / 候选已就绪 · 在键盘选回复 / 等待聊天画面 …），分析中有粉点

## 风格
对齐落地页：#F04B7A 粉、#FF8FB0 浅粉、#C42A5A 深粉、#FFE3EC 腮红、墨色 #2B1D24、系统字体（PingFang）。
粉白渐变底；头像 135° 粉色渐变；落地页「好感度」卡片用的是圆环仪表。

## 当前问题（真机截图）
抬头与粉点挤进圆角；名字被截断；建议断行生硬；上挤下空；心形太小；分数与变化值抢位。
